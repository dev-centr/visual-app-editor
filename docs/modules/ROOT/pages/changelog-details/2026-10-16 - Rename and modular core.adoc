= 2026-10-16 - Rename and modular core
:page-audience: Developer

== Rename

* The project is now *Visual App Editor*: repository `dev-centr/visual-app-editor`, app and executable `visual_app_editor`, installers `VisualAppEditor-<version>-...`, CI artifacts `visual-app-editor-<os>-<arch>`.
* The project settings file is `visual_app_editor.sdl`. Projects with only a `widget_bench.sdl` still open, and the next save writes the new name.
* Docs: https://docs.devcentr.org/visual-app-editor/.

== Modular architecture

* `packages/core` (`vae_core`): tree model, toolkit catalog, edit operations, device presets, SDL, and the adapter interface, with no framework dependency.
* `packages/protocol` and `packages/service`: a headless editing service over JSON-RPC 2.0 with LSP-style framing, usable on stdio or in process. See xref:protocol.adoc[].
* `adapters/dart`: the existing analyzer-based Flutter support, moved out of the app.
* `adapters/react`: new React and React Native adapter on the TypeScript compiler API. It finds components, builds the JSX tree, round-trips all edit operations, and catalogs DOM, React Native and installed packages by type introspection.
* `apps/desktop`: the editor app now talks to the service. The toolbar has a phone / tablet / desktop / web mode switcher with presets per mode.
* `plugins/intellij`, `plugins/vscode`: planned front ends (skeletons only).

See xref:spec.adoc[] for the architecture and roadmap.
