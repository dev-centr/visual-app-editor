= Visual App Editor
:page-audience: Developer

Visual App Editor is an offline visual editor for app screens: Flutter today, with React and React Native adapters coming.
It edits the source files in your project directly, so hand-written code stays where you put it, and it can load widgets from Material, Cupertino, or third-party packages such as shadcn_ui, forui, fluent_ui and macos_ui.
