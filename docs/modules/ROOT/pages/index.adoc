= Widget Bench
:page-audience: Developer

Widget Bench is an offline desktop app for building Flutter screens visually.
It edits the Dart files in your project directly, so hand-written code stays where you put it, and it can load widgets from Material, Cupertino, or third-party packages such as shadcn_ui, forui, fluent_ui and macos_ui.
